# Bench playbook

## Objetivo

Dar a colaboradores en bench una ruta clara para crear templates útiles mientras desarrollan habilidades prácticas.

## Ciclo de trabajo

1. Seleccionar issue priorizado.
2. Crear rama.
3. Construir template desde scaffold.
4. Probar importación o ejecución.
5. Agregar evidencia.
6. Abrir PR.
7. Recibir review y ajustar.

## Criterios de calidad

- El template resuelve un caso de uso real.
- Puede reproducirse con el README.
- No contiene secretos.
- Tiene smoke test.
- Declara riesgos y permisos.
