# Langflow Research Agent

**Status:** `draft` — flow oficial de Langflow, requiere Langflow 1.x instalado.
**Fuente:** Official Langflow starter project — MIT

Langflow 1.x + OpenAI + Search tools — ver [Langflow docs](https://docs.langflow.org) para setup.

## Importar

1. Instalar Langflow: `pip install langflow && langflow run`
2. UI en `http://localhost:7860` → ícono carpeta → **Load Flow** → `src/flow.json`
3. Configurar API keys en los nodos del UI

## Dependencias

Langflow 1.x + OpenAI + Search tools

## Limitaciones

- Compatible con Langflow 1.x. Verificar compatibilidad de nodos al importar.
- Status `draft`: no probado en entorno real del equipo.
